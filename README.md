# aklairport

奧克蘭機場實時航班（離港閘口）· Auckland Airport live flights with departure gates.

- Site: https://ittonywong.github.io/aklairport/
- Data: AeroDataBox (https://aerodatabox.com) via the Cloudflare Worker akl-flights-proxy. No API key is stored in this repository.
- Data may be delayed or incomplete; always check with your airline and the airport screens.
